# Internal integration contracts

Python package src/writune. All modules use Settings from config.py.

Settings: Pydantic model with data_dir:Path, allowed_workspaces:list[Path], providers:dict[str,ProviderConfig], zh_primary/zh_secondary/en_primary/en_secondary:str (provider/model), max_concurrency=4,max_queue_size=200,retry_count=1, worker_idle_seconds=30,lease_seconds=15,task_ttl_hours=24, default_scene='general_prose',default_style='natural',profiles:dict. timeout settings: connect_timeout=8, first_token_timeout=25,inactivity_timeout=20,total_timeout=120,min_tps=6,tps_window=10,tps_warmup_tokens=30,tps_warmup_seconds=10,consecutive_slow_windows=2. Settings.load() loads WRITUNE_HOME/config.json + .env; save(). db_path property. ProviderConfig: base_url,api_key:SecretStr,max_concurrency=4,model_concurrency:dict,capabilities:dict,parameters:dict,cache:dict,tokenizer optional,prices:dict, timeout overrides optional.

Provider API: async ResponsesProvider(provider:ProviderConfig, settings:Settings).generate(model:str,prompt:Prompt,options:dict|None=None)->Generation. Prompt has prefix:str,input:str. Generation has text, input_tokens, output_tokens,cached_input_tokens,cache_write_tokens,first_token_latency,generation_tps,total_elapsed,tps_estimated. ProviderError(code,message,retryable=True) sanitizes messages. Each generate owns context-managed httpx connection and supports asyncio cancellation.

Polishing: build_prompt(text, language='en',scene='general_prose',style='natural',context=None,local_context='',custom_templates=None)->Prompt. protect(text)->ProtectedText with text (masked), restore(output)->str; validate(original,output)->None raises ValidationError. segmentation.segment_markdown(text)->list[str]. contexts content hashing supported by service database.

Files: Workspace(allowed_roots:list[Path],task_root:Path).check(path,write=False)->Path; atomic_write(path,data:bytes,overwrite=True); apply_result(result_path,target_path,placeholder_id,output_path=None,overwrite=False,workspace=None)->dict. Settings.task_dir is always OS temporary storage, independently of the persistent data_dir. Default applied copies and digest records stay in temporary storage; output_path explicitly selects the final document. Supports txt/md/tex/docx. Provider does not apply files. Windows MCP and workers use pythonw.exe without shell wrappers or visible consoles.

Primary agent owns tasks/* and service.py: Service(settings=None,start_worker=True), create_context(**kwargs),submit(**kwargs),submit_batch(items=None,source_paths=None,markdown_path=None,**kwargs),status(task_id=None,batch_id=None),result(task_id,inline_text=False),apply(**kwargs),cancel(task_id),health(),stats(),cleanup(). Synchronous methods, worker is separate process. Returns JSON serializable dicts. submit accepts text/source_path exclusive, context_id/language/scene/style/models/priority/idempotency_key/profile/local_context/options. Service.settings public. Worker invoked python -m writune.tasks.worker. All CLI/MCP use Service. CLI/MCP agent can assume methods above.

Agents own only assigned directories/files; do not edit others. Tests named test_<area>*.py. Use .venv/Scripts/python.exe. No subagents. Use official SDK FastMCP available from mcp.server.fastmcp; confirm installed version. Avoid experimental Tasks API.
